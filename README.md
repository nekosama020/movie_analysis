# 🎬 Hệ thống Phân tích và Dự đoán Dữ liệu Phim

Dự án này là một Dashboard tương tác được xây dựng bằng **Python** và **Streamlit**. Hệ thống hỗ trợ thực hiện toàn bộ quy trình Khoa học dữ liệu bao gồm: Tiền xử lý, Trực quan hóa và Huấn luyện mô hình Machine Learning (Hồi quy) để dự đoán doanh thu và điểm đánh giá phim.

## 🚀 Hướng dẫn cài đặt và chạy dự án

1. **Clone dự án về máy:**
   ```bash
   git clone <đường_link_github_của_bạn>
2. **Kích hoạt môi trường ảo (venv) và cài đặt thư viện:**

Bash
pip install -r requirements.txt
3. **Khởi chạy ứng dụng:**

Bash
streamlit run app.py
*(Nhấn `Ctrl + S` để lưu lại).*
